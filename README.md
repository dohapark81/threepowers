# 삼권 三權 — threepowers

> 공식 원문만으로 구성된 기록 보관소. 해석도 결론도 없습니다.

선거관리위원회·국회·법원에 관한 공식 기록(선관위 발표, 국회 문서, 관보, 법령)을
날짜순으로 쌓고, 모든 항목에 원문 링크를 답니다.

- **선관위 구성 지도** — 중앙선관위원 9인은 누가 임명했나
- **6·3 사태 기록 타임라인** — 투표용지 부족 사태의 공식 발표 기록
- **국정조사 추적기** — 절차 단계·특위 구성·증인 명단

## 원칙

1. 어떤 주장도 판정하지 않습니다. 상태 라벨은 `공식발표 | 조사중 | 조사결과 발표 | 정정됨` 4종뿐입니다.
2. 원문 링크 100%. 단독 보도는 수록하지 않습니다.
3. 정정은 삭제가 아니라 기록입니다 (`supersedes` 체계, 커밋 이력 공개).
4. 데이터 변경은 에이전트가 PR을 만들고, 머지는 사람이 합니다.

데이터 스키마와 수록 원칙은 [data/README.md](data/README.md) 참고.

## 개발

```bash
npm install
npm run dev    # http://localhost:4321/threepowers
npm run build  # dist/ 정적 빌드
```

Astro 정적 사이트로, `main` 푸시 시 GitHub Actions가 GitHub Pages에 배포합니다.
콘텐츠는 전부 [data/](data/)의 JSON에서 나옵니다.

이 서비스의 수집·요약·배포는 [CrewX](https://github.com/sowonlabs/crewx) 에이전트가 수행합니다.
