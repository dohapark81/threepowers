# 핵심 흐름 — 가로 칩 → 세로 뉴스형 타임라인으로 표현 교체

## Background (Why)

WI-20260611-02 로 사태기록 상단에 **가로 칩 스트립**(`핵심 흐름`)을 깔았다(커밋 `58aff7a`, PR #2 draft).
사용자 요청: 뉴스 기사의 "주요 타임라인 요약"처럼 **세로 레일 + 노드** 형태로 바꾸고 싶다.
각 노드에 날짜·상태배지·굵은 라벨·설명 한 줄을 담아, 한눈에 사태 전개를 읽게 한다.
아래 전체 사건기록(`TimelineList`)과 채용비리 배경은 **지금 그대로** 둔다.

이건 **순수 표현 교체**다. "어느 항목이 전환점인가"(pivot 6개)와 라벨은 WI-02 에서 확정·구현돼 있고,
앵커 점프 배관(`#evt_id`)도 이미 동작한다. 따라서 데이터·타입·페이지 삽입부는 **전혀 건드리지 않는다.**

## Goal (What)

`KeyEvents.astro` 의 **렌더 마크업**과 `global.css` 의 **칩 CSS 블록**만 교체해서,
가로 칩 → **세로 뉴스형 타임라인**으로 바꾼다. 데이터 흐름(`events.filter(pivot)` → 날짜 오름차순)·
앵커 링크(`#${evt.id}`)·상태색 매핑은 **동일하게 유지**한다.

### 노드 한 개의 구성 (확정)

```
 ●  2025.12.10   [공식발표]      ← 상태 점(레일 위) · 날짜(mono) · 상태배지
 │   인쇄하한 60→50%             ← pivot.label (굵게)
 │   선관위, 투표용지 인쇄 하한선 60%→50% 하향   ← title (설명 한 줄, muted)
 │
 ●  2026.06.03   [공식발표]
 │   투표 중단·재개
 │   일부 투표소 투표용지 부족으로 투표 중단·재개
 │
 ⋮  (6·5 위원장 사퇴 표명 / 6·8 국정조사 요구 / 6·9 합수본 출범)
 │
 ○  2026.06.11   [조사중]        ← 6·11 만 hollow ring(주황 테두리) + 조사중 배지
     7곳 압수수색
     경찰·합수본, 중앙선관위 등 7곳 압수수색
```

- **굵은 줄** = `evt.pivot.label` · **설명 줄** = `evt.title` · **배지** = `EVENT_STATUS_LABEL[evt.status]`
- 노드 전체가 링크 → 클릭 시 아래 전체기록의 해당 `#${evt.id}` 로 점프 (배관 이미 있음)
- **상태 점**: 공식발표 5건 = 채워진 점(짙은색) / 6·11 조사중 = **빈 링(주황 테두리)**.
  ⚠️ **체크표시(✓) 쓰지 말 것** — "완료/확정"으로 읽혀 중립 기록 원칙과 충돌. 상태색 점만 사용.
- 정렬은 **날짜 오름차순**(전개 순서, 위→아래) — 아래 전체 리스트(내림차순)와 다른 게 정상.

## Implementation Guide (How)

> 아래 코드는 **그대로 복붙**하면 동작한다. 라벨·선정·상태는 WI-02 에서 확정됐으니 손대지 말 것.

### T1 — `src/components/KeyEvents.astro` 전체 교체

파일을 아래 내용으로 **통째 교체**한다. (변경점: ① `EVENT_STATUS_LABEL` import 추가
② 날짜 포맷 `M·D` → `YYYY.MM.DD` ③ 렌더 블록을 세로 레일로 교체. 필터·정렬·STATUS_CLASS 는 동일)

```astro
---
import { EVENT_STATUS_LABEL, type TimelineEvent } from '../lib/types';

interface Props {
  events: TimelineEvent[];
  /** 항목 앵커 링크의 베이스 경로. 같은 페이지면 빈 문자열 */
  anchorBase?: string;
}

const { events, anchorBase = '' } = Astro.props;

// pivot 표시된 항목만, 날짜 오름차순(전환점을 전개 순서대로 위→아래)
const pivots = events
  .filter((e) => e.pivot)
  .sort((a, b) => a.date.localeCompare(b.date) || a.id.localeCompare(b.id));

// TimelineList 와 동일한 상태→색 매핑
const STATUS_CLASS = {
  official: 'b-official',
  investigating: 'b-progress',
  result_announced: 'b-result',
  corrected: 'b-correct',
} as const;

// 'YYYY-MM-DD' → 'YYYY.MM.DD'
const dotDate = (d: string) => d.replace(/-/g, '.');
---

{pivots.length > 0 && (
  <nav class="keyflow" aria-label="핵심 흐름 요약">
    <span class="keyflow-label">핵심 흐름</span>
    <ol class="keyflow-rail">
      {pivots.map((evt) => (
        <li class="kf-node">
          <a class="kf-link" href={`${anchorBase}#${evt.id}`}>
            <span class:list={['kf-dot', STATUS_CLASS[evt.status]]} aria-hidden="true" />
            <span class="kf-meta">
              <time class="kf-date">{dotDate(evt.date)}</time>
              <span class:list={['badge', STATUS_CLASS[evt.status]]}>{EVENT_STATUS_LABEL[evt.status]}</span>
            </span>
            <span class="kf-label">{evt.pivot!.label}</span>
            <span class="kf-title">{evt.title}</span>
          </a>
        </li>
      ))}
    </ol>
  </nav>
)}
```

### T2 — `src/styles/global.css` 칩 블록 교체

현재 `/* ── key-flow chip strip ── */` 주석부터 `.klabel { … }` 까지(약 178~198행)를
**아래 블록으로 통째 교체**한다. 바로 다음의 `/* ── inquiry stage strip ── */`(`.stages-scroll` 등)은
**그대로 둔다**(삭제·수정 금지 — inquiry 페이지가 쓴다).

```css
/* ── key-flow vertical timeline ─────────────────── */
.keyflow { margin: 2px 0 26px; }
```

> 점 디자인: 공식발표 = 채워진 점(`background`+`border` 둘 다 짙은색), 조사중 = 빈 링(`background:var(--paper)`+주황 테두리).
> `box-shadow` 의 `--paper` 헤일로가 점 주변에서 레일선을 깔끔히 끊어 준다. 체크표시 절대 금지.

> 모바일: 세로 레이아웃이라 가로 스크롤 불필요. 기존 `@media(max-width:720px)` 블록은 손대지 않아도
> 13px+1fr 그리드가 자연 스택된다. 별도 모바일 CSS 불요.
