## 배경 / 결정

사용자 결정: **타임라인 방향을 통일한다(최신순)**. 근거 — "사람들은 단순하다. 통일성이 있어야 맥락이 잘 잡힌다."

현재 같은 `timeline.astro` 안에서 두 컴포넌트가 **반대 방향**으로 흐른다:

| 컴포넌트 | 현재 정렬 | 방향 |
|---|---|---|
| `KeyEvents` (핵심 흐름 요약) | **오름차순** `a.date.localeCompare(b.date)` | 12·10 위 → 6·11 아래 (오래된 게 위) |
| `TimelineList` (전체 기록) | **내림차순** `b.date.localeCompare(a.date)` | 6·11 위 → 12·10 아래 (최신이 위) |

전체 기록(`TimelineList`)이 **이미 최신순**이므로, 통일을 위해 바꿀 것은 **`KeyEvents` 하나뿐**이다 — 오름차순 → 내림차순으로 뒤집으면 두 타임라인의 비교자가 **글자 단위로 동일**해진다.

## T1 — KeyEvents 정렬 뒤집기 (이게 전부)

파일: `src/components/KeyEvents.astro` (현재 12–15행)

**현재:**
```js
// pivot 표시된 항목만, 날짜 오름차순(전환점을 전개 순서대로 위→아래)
const pivots = events
  .filter((e) => e.pivot)
  .sort((a, b) => a.date.localeCompare(b.date) || a.id.localeCompare(b.id));
```

**변경 후:**
```js
// pivot 표시된 항목만, 날짜 내림차순(최신순) — 아래 TimelineList 와 방향 통일
const pivots = events
  .filter((e) => e.pivot)
  .sort((a, b) => b.date.localeCompare(a.date) || b.id.localeCompare(a.id));
```

즉 비교자의 `a`/`b`를 맞바꾸기만 한다(`TimelineList.astro` 14행과 동일해짐). 주석도 함께 갱신. **그 외 마크업·CSS·필터·앵커는 한 글자도 바꾸지 말 것.**
