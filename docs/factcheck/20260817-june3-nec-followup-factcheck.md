# 6·3 선관위·국정조사 10시 수집분 팩트체크 — 2026-08-17

검수 대상은 직전 팩트체크 뒤 현재 브랜치에만 있는 `8f73b6f`(국정조사특위 활동기간 연장 표결 확인)와 `e2e2f49`(부산시선관위 조치 집계 수록)이다. 결론은 **부산시선관위 조치 기사는 승인**, **국정조사 데이터는 활동기한 날짜 1건을 정정 후 승인**이다.

## 사실 대조

### `inquiry.json` — 국정조사특위 활동기간 연장

- [국정조사특위 제7차 회의록](https://record.assembly.go.kr/assembly/viewer/minutes/xml.do?id=57071&type=view)은 2026년 8월 1일 종료 예정이던 활동기한을 **2026년 8월 31일까지 30일간** 연장하는 위원회안을 가결했다고 명시한다. [제3차 본회의 회의록](https://record.assembly.go.kr/assembly/viewer/minutes/xml.do?id=57050&type=view)도 의안 2220308을 재석 225명 전원 찬성으로 가결했다. 의안정보시스템의 [2220308 처리 상태](https://likms.assembly.go.kr/bill/billDetail.do?billId=PRC_U2Y6S0D7E3X0F1V4G3W1D0R2R2W1V5)도 원안가결이다.
- 따라서 `data/inquiry.json`의 위원회안 날짜가 8월 30일로 남아 있던 것은 오류다. 8월 31일로 정정했다. 본회의 표결 수와 활동기간은 원문과 일치한다.
- 보관한 `docs/sources/assembly/20260730-plenary-minutes-57050.pdf`는 국회 원본 PDF와 SHA-256 값이 일치한다. 회의록은 정당의 주장이나 증언의 진위를 채택하지 않고, 의안·표결·일정만 기록한다.

### `evt_20260815_01` — 부산시선관위 조치 집계

- [KBS](https://news.kbs.co.kr/news/view.do?ncd=8638077)와 [연합뉴스](https://www.yna.co.kr/view/AKR20260814115000051) 원문은 모두 16건 고발과 10건 수사의뢰, 경고 등 127건, 합계 153건을 보도한다. 데이터의 26건·127건·153건 수치 및 투표지 훼손·촬영·공개 43건, 시설물·인쇄물 훼손 32건, 기부행위 19건, 허위사실 공표 15건, 공무원 등의 선거개입 6건도 일치한다.
- 데이터는 `혐의`, `고발·수사의뢰`, `조치`로 범위를 한정한다. 수사 대상의 유죄나 특정 정당·후보의 책임을 확정하지 않는다. 기사와 데이터 모두 정당명·이념적 평가를 포함하지 않아 특정 정치성향을 강화하는 편집은 확인되지 않았다.

## 무결성·배포 범위

- 두 수집 커밋의 신규·변경 원문 URL 5건은 재요청 결과 모두 HTTP 200이다.
- `data/events.json`과 `data/inquiry.json`은 JSON 파싱을 통과했고, `events.json`의 이벤트 ID 122개는 중복이 없다.
- 이 검수 커밋에는 위 날짜 정정과 검수 기록만 포함한다. 기존 `crewx.yaml` 변경 및 미추적 `docs/research/`·`memory/`·`skills/`는 포함하지 않는다.
